# Installable Mobile-First PWA Over Native Mobile App

We will build Monster GymRats as an installable mobile-first Progressive Web App (Next.js) rather than a native iOS/Android store app. Friend-group apps depend on zero-friction viral invite links, and a PWA lets friends join a Club and log a can in seconds without App Store approval delays or download barriers. Because iOS Safari requires home-screen installation for Web Push notifications and optimal full-screen camera feel, we will build an interactive in-app "Add to Home Screen" onboarding tutorial as a first-class feature.
